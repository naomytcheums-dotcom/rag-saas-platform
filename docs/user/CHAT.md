# Chat

## Starting a conversation

Go to **Chat**, click **New conversation**, and ask a question. The
assistant searches your organization's documents (see
[Search](SEARCH.md)) and answers with citations back to source passages
(see [Citations](CITATIONS.md)).

## Streaming answers

Responses stream in as they're generated rather than appearing all at
once.

## Talking to a specific agent

If your organization has configured one or more [agents](AGENTS.md)
(a persona with a specific system prompt and tool access), you can pick
one from the conversation's agent selector instead of using the default
assistant.

## Voice

If enabled, you can ask questions by voice and have answers read aloud —
see [Voice](VOICE.md).

## Sharing a conversation

Conversations can be shared with a link (subject to your organization's
sharing settings). Open a conversation, use **Share**, and choose the
access level.

## Giving feedback

Thumbs up/down on any answer — see [Feedback](FEEDBACK.md). This feeds
into evaluation and, for administrators, quality dashboards.
