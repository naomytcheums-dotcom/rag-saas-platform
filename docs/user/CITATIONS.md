# Citations

Every generated answer includes citations back to the specific source
passages it was grounded in. Click a citation marker to jump to the
source document and the exact chunk that was used.

## Why citations matter here

This isn't cosmetic — the platform's citation and anti-hallucination
checks are designed to make ungrounded claims visible rather than
silently present as fact. If an answer includes a claim that isn't
well-supported by retrieved passages, it should be flagged rather than
cited to a passage that doesn't actually support it.

## No citation available

If the assistant cannot find supporting passages for part of an answer,
it should say so rather than fabricate a citation. If you see an answer
you believe is ungrounded or miscited, use [Feedback](FEEDBACK.md) —
this is exactly the kind of signal the platform's evaluation and
regression-detection tooling is built to catch.
