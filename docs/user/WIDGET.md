# Widget

The chat widget lets you embed this platform's assistant on any website
via a script tag — no iframe integration work required.

## For end users

If you're chatting with a business through their embedded widget rather
than the platform's own dashboard, you're using the same underlying
chat/retrieval/citation system described in [Chat](CHAT.md) — it's just
skinned and hosted differently.

## Embedding a widget on your own site

This is a developer/admin task. See
[`docs/widget/SCRIPT_TAG.md`](../widget/SCRIPT_TAG.md) for the script
tag, [`docs/widget/CUSTOMIZATION.md`](../widget/CUSTOMIZATION.md) for
theming, and [`docs/widget/EXAMPLES.md`](../widget/EXAMPLES.md) for
worked examples. Also see
[Widget Embed](../developer/WIDGET_EMBED.md) in the Developer Guide.
