# Account Setup

## Creating an account

Depending on your deployment, you either sign up directly or accept an
invitation email from an organization admin (see
[Members & Invitations](../admin/MEMBERS_AND_INVITATIONS.md) for the
admin side of this).

## Password and login

Standard email/password login is always available. If your organization
has enabled single sign-on, you may see an SSO login option instead —
ask your admin which method applies to you (see
[SSO](../admin/SSO.md)).

## Securing your account

- **Two-factor authentication (2FA)** — enable it from Settings →
  Security. Adds a one-time code requirement on login.
- **WebAuthn / security keys** — supported as an alternative or
  addition to 2FA, for hardware keys or platform authenticators
  (Touch ID, Windows Hello).

## Switching organizations

If you belong to more than one organization, use the organization
switcher in the dashboard header. Your role and permissions can differ
per organization.

## Profile

Set your display name and notification preferences under Settings → see
[Settings](SETTINGS.md) and [Notifications](NOTIFICATIONS.md).
