# RAG SaaS Platform — Documentation

Welcome. This documentation covers the multi-tenant RAG SaaS platform
built in `api/` + `frontend/`. If you're looking for the original
single-tenant RAG evaluation project this platform grew from, see
[`src/README.md`](../src/README.md) instead.

## Start here

- New to the platform? [`user/GETTING_STARTED.md`](user/GETTING_STARTED.md)
- Deploying or self-hosting? [`install/`](install/)
- Building on the API or an SDK? [`developer/`](developer/)
- Administering an organization? [`admin/`](admin/)
- Looking up an endpoint? [`api/`](api/)
