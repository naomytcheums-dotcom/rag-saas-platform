# Audit statique des tables liées indirectement au tenant

Date : 2026-10-03. Inventaire calculé depuis les métadonnées ORM locales et références textuelles/AST des routers/tests. **Il ne valide ni schéma DB live, ni execution SQL, ni authorization runtime.** Chaque « chemin tenant » est une chaîne de FK vers une table contenant `organization_id`; pour les tables dont le propriétaire pourrait être utilisateur ou partagé, ceci reste une hypothèse à valider.

Tables avec chemin FK candidat vers un parent possédant organization_id et sans colonne organization_id directe : **63**. En raison d une variation de spécification qui évoque 98 tables sans org direct mais dont 24 sont User-scoped/global/system, cet audit liste seulement les 63 chemins indirects de la matrice, pas toutes les 98 tables non-directes.

Les informations router/endpoints, guards, filtres, IDOR et tests sont conservatrices : une recherche d occurrence de nom ne prouve pas qu une route accède à la table. `UNKNOWN` identifie cette limite et n est pas une affirmation d absence de garde.
