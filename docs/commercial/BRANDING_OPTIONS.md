# Options de nom, logo et palette

Ce document est une proposition de direction visuelle, non une décision de marque définitive.

## 1. Nom

Options de proposition :
- RAG Evolution Factory
- RAG Workspace
- Knowledge Flow
- Document Intelligence Stack

## 2. Logo

Les pistes réalistes sans supposer des ressources graphiques créées dans le dépôt :
- symbole de document avec un point de recherche / flèche
- stack de couches / fragments de document
- forme de lien / graphe de connaissance
- monogramme avec initiales ou mot-clé RAG

## 3. Palette

Palette proposée comme base de travail :
- primaire : bleu foncé #0F172A
- secondaire : cyan #22D3EE
- accent : violet #8B5CF6
- neutre : gris #E2E8F0
- fond : blanc #F8FAFC

## 4. Règle de sélection

Aucune option n'est tranchée ici ; ce document ne fait que proposer des axes de marque pour une validation utilisateur ou marketing plus tard.
