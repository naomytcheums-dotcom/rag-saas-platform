# Exact versions frozen from the environment this project was actually
# built and tested against (Python 3.13, Windows). Pinned deliberately --
# see AUDIT.md: an earlier unpinned `anthropic` install resolved to 0.34.2,
# which crashed on every call because it passes a `proxies` kwarg to httpx
# that httpx>=0.28 no longer accepts. If you need a different version,
# relax the pin and re-run `pytest tests/` + `python tests/test_regression.py`
# before trusting the result.

# Stage 1: ingestion (src/ingestion.py)
# Uses only the Python standard library -- no external packages required.

# Stage 2: indexing (src/indexing.py)
# torch is a transitive dep of sentence-transformers, otherwise left
# unpinned -- on Linux that resolves pip's default CUDA-enabled build,
# pulling several GB of nvidia-*-cu12 packages this CPU-only app (no GPU
# in local dev, CI, or deploy) never uses. That bloat was landing inside
# the Dockerfile's builder-stage venv and then getting copied whole into
# the final image, which is what was blowing past the GitHub Actions
# runner's disk budget in the docker-build job ("No space left on
# device"). Pinned here to the CPU-only wheel from PyTorch's own index
# instead, matching what local dev already runs.
--extra-index-url https://download.pytorch.org/whl/cpu

chromadb==1.5.9
