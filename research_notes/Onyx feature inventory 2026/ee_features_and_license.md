# Onyx (onyx-dot-app/onyx) — Enterprise Edition Features and License Structure

## Question 1: What exact license structure governs Onyx, and what does an EE license grant?

### Takeaway
Onyx uses a dual-license, source-available model: everything outside `ee/`-named directories is MIT ("MIT Expat"), an OSI-approved permissive open-source license, while code physically located inside `backend/ee/`, `web/src/app/ee/`, and `web/src/ee/` is publicly visible in the same GitHub repo but governed by a separate, proprietary "Onyx Enterprise License" that forbids production use, copying, redistribution, or resale without a paid subscription. There is no BUSL-style time-delayed open-sourcing clause found — the Enterprise License is a permanent, closed-terms proprietary grant, not an OSI license and not a "fair source"/BUSL license with an automatic conversion date.

### Cited Findings
- The repo-root `LICENSE` file states: "Copyright (c) 2023-present DanswerAI, Inc. Portions of this software are licensed as follows: All content that resides under 'ee' directories of this repository is licensed under the Onyx Enterprise License. Each ee directory contains an identical copy of this license at its root: `backend/ee/LICENSE`, `web/src/app/ee/LICENSE`, `web/src/ee/LICENSE`. All third party components incorporated into the Onyx Software are licensed under the original license provided by the owner of the applicable component. Content outside of the above mentioned directories or restrictions above is available under the 'MIT Expat' license..." followed by the standard MIT permission/warranty text — [LICENSE](https://github.com/onyx-dot-app/onyx/blob/main/LICENSE)
- The MIT Expat portion grants the standard rights to "use, copy, modify, merge, publish, distribute, sublicense, and/or sell" the (non-EE) software, conditioned only on retaining the copyright/license notice, with a standard "AS IS" warranty disclaimer — [LICENSE](https://github.com/onyx-dot-app/onyx/blob/main/LICENSE)
- The separate license at `backend/ee/LICENSE` (identically copied to `web/src/app/ee/LICENSE` and `web/src/ee/LICENSE`) is titled "The Onyx Enterprise License," copyrighted to DanswerAI, Inc. (2023–present). It restricts **production use** to holders of "a valid Onyx Enterprise License for the correct number of user seats" who comply with the "Onyx Subscription Terms of Service." Users may modify the software and create patches for development/testing without a subscription, but "all right, title and interest" in any modifications remains with DanswerAI, and the license "explicitly forbids copying, merging, publishing, distributing, sublicensing, or selling the software" — [backend/ee/LICENSE](https://github.com/onyx-dot-app/onyx/blob/main/backend/ee/LICENSE)
- The README states: "There are two editions of Onyx: Onyx Community Edition (CE) is available freely under the MIT license and covers all of the core features for Chat, RAG, Agents, and Actions. Onyx Enterprise Edition (EE) includes extra features that are primarily useful for larger organizations." — [README.md](https://github.com/onyx-dot-app/onyx/blob/main/README.md)
- Onyx offers trial access rather than a private repo: "If you'd like to try Enterprise Edition, try Onyx Cloud for free with no limitations to the features or usage of the Cloud trial, or contact us at hello@onyx.app for a free self-hosted trial" — [README.md via search](https://github.com/onyx-dot-app/onyx/blob/main/README.md)
- A separate GitHub project, `onyx-dot-app/onyx-foss`, exists, described as "Open Source AI Platform," suggesting a pure-FOSS mirror/variant without EE directories, though its exact relationship (fork vs. stripped mirror) was not independently confirmed in this pass — [onyx-foss repo](https://github.com/onyx-dot-app/onyx-foss)

### Inferences
- Because the EE code lives in the public `onyx-dot-app/onyx` repo under `ee/` directories, EE is **source-available, not closed-source**: anyone can read the EE source, but the license (not a technical key-gate alone) prohibits running it in production, copying it, or redistributing it without paying for an Enterprise License covering the correct user-seat count. This is a classic "visible source, restricted-use" proprietary license — closer in spirit to BUSL-style source-available licenses than to OSI open source, but without the BUSL hallmark of an automatic future conversion to a permissive license; no such conversion clause was found in the fetched EE LICENSE text.
- "Purchasing an EE license" therefore grants a **contractual right to run existing EE code already present in the repo** (a license/seat entitlement, likely enforced partly by the Onyx Subscription Terms of Service and possibly a license key at runtime) rather than access to separate private source code.
- The MIT-vs-Enterprise-License split is enforced by directory location within one repository, not by a separate access-controlled repo — precision note: the three canonical EE directories are `backend/ee/`, `web/src/app/ee/`, and `web/src/ee/`.

### Gaps
- Could not confirm from primary sources whether a runtime "license key" technically gates EE features (e.g., feature flags checked against a license server) versus enforcement being purely contractual/legal. The EE LICENSE text describes legal restriction on production use but the fetched summary did not mention a technical key mechanism.
- Could not verify the exact relationship between `onyx-dot-app/onyx` and `onyx-dot-app/onyx-foss` (e.g., whether onyx-foss strips the ee/ directories entirely) — this would need a direct repo file-listing comparison, which was not performed.
- Full verbatim text of the Enterprise License Terms of Service (referenced as "Onyx Subscription Terms of Service") was not located/fetched — only the LICENSE file's summary of it.
- Could not confirm whether "DanswerAI, Inc." is still the current legal entity name in 2026 (the project rebranded from Danswer to Onyx, but the copyright holder name in the LICENSE file, as fetched, still reads "DanswerAI, Inc.").

## Question 2: Complete enumeration of Enterprise Edition ("EE"/paid-only) features

### Takeaway
Onyx's EE feature set clusters into five areas: enterprise authentication/identity (OIDC/SAML SSO with SCIM provisioning), access-governance (RBAC, permission sync/inheritance from external systems, group-based fine-grained permissions), admin visibility (usage analytics, query history/audit), branding (whitelabeling), and deployment/operational extras (encrypted secrets management, hook extensions/custom code execution, EE-specific APIs, priority/dedicated support, on-prem and region-specific deployment, data exports). Some items (basic RBAC, permission inheritance, query history/usage dashboards) appear to have migrated to the standard paid "Business" cloud tier rather than being Enterprise-exclusive — see tier mapping in Question 3.

### Cited Findings
- Onyx's official Enterprise Edition docs page lists these EE features (paraphrased/quoted from the page): **OIDC/SAML** — "SSO authentication with OpenID Connect and SAML 2.0 providers"; **Permission Sync Connectors** — "automatically inherit user permissions from external systems"; **Whitelabeling** — "Customize branding, logos, and styling to match your organization"; **User Groups & RBACs** — "Organize users and maintain fine-grained RBACs"; **Group-Based Permissions** — "Fine-grained, group-based access control for Connectors, Document Sets, and Agents" (noted as available "in v4.7+"); **Usage Analytics** — "Detailed insights into user queries and system usage"; **Encrypted Secrets** — "Enterprise-grade encryption for all sensitive credentials and API keys"; **Enterprise Edition APIs** — "Extended API access for Enterprise Edition features"; **Priority Support** — "Dedicated support with guaranteed response times and white-glove deployment assistance"; **Hook Extensions** — "Inject custom logic into Onyx's pipeline at defined stages without modifying source code" — [Enterprise Edition docs](https://docs.onyx.app/deployment/miscellaneous/enterprise_edition)
- The same docs page notes "Onyx Cloud includes all Enterprise Edition features" and offers "a free trial with no feature limitations" — [Enterprise Edition docs](https://docs.onyx.app/deployment/miscellaneous/enterprise_edition)
- The GitHub README's "Onyx for Enterprise" section lists: Collaboration (shared chats and agents), Single Sign On (Google OAuth, OIDC, SAML — "with SCIM support" per the README), Role-Based Access Control for sensitive resources, Analytics and usage reporting, Query history and audit capabilities, Custom code execution for data filtering, and Whitelabeling options — [README.md](https://github.com/onyx-dot-app/onyx/blob/main/README.md)
- Onyx has dedicated SCIM 2.0 documentation describing automated user/group provisioning: "automated user and group provisioning with SCIM 2.0, including user provisioning to automatically create Onyx accounts when users are assigned in your IdP, user deprovisioning to deactivate accounts when users are unassigned or suspended, group sync to push group membership changes, and profile updates to keep user attributes in sync," configured via "Admin Panel → Permissions → SCIM" — [SCIM docs](https://docs.onyx.app/deployment/authentication/scim)
- The onyx.app/pricing page lists, as Enterprise-tier-exclusive add-ons beyond the paid "Business" tier: OIDC/SAML SSO, On-Premise Deployments, Region-Specific Deployments, Early Access to Features, White-labelling, Custom Integrations, Hook Extensions, Data Exports, Invoice Billing, Volume Discounts, Higher Education Pricing, Dedicated Support, Enterprise SLA — [onyx.app/pricing](https://onyx.app/pricing)
- A general web search summary states Enterprise Edition "uses a contract model with two separate pricing dimensions: you pay based on the number of users who have access to Onyx and the number of Onyx instances you run" — [search summary, unverified against a primary Onyx-owned page](https://www.saasworthy.com/product/onyx-app/pricing)

### Inferences
- Cross-referencing the docs EE-feature list against the pricing page's Business-tier list reveals that RBAC, permission inheritance, and query history/usage dashboards are now bundled into the $20/user/month "Business" self-serve tier (see Q3), meaning the strict EE/paid-license boundary as coded in the repo (the `ee/` directories) is broader than what Onyx currently markets as "Enterprise-only" on pricing — i.e., some code that legally requires an Enterprise License to run in production is being offered to Business-tier cloud customers as part of Onyx's own hosted offering (Onyx being the licensor, it can offer EE code to any tier it chooses on its own Cloud).
- SCIM provisioning is documented as a distinct capability tied to enterprise SSO/identity and, per the README, bundled with the SSO feature set — it should be treated as an EE/enterprise-tier capability, consistent with typical SCIM industry positioning, though the docs EE feature list does not name "SCIM" as its own bullet (it's implied under "OIDC/SAML" per README wording "with SCIM support").

### Gaps
- Could not find an explicit, complete list of "EE-only" features as a single canonical page distinguishing exactly which of these are gated by the `ee/` code license versus which are Cloud-only infrastructure features (e.g., is on-prem/region-specific deployment a licensing restriction or simply a deployment-topology offering?). This distinction matters for the report's "EE = paid license required" framing but the primary sources conflate "Enterprise Edition" (a license/code concept) with "Enterprise tier" (a pricing/contract concept).
- Could not verify from a primary source whether "custom LLM provider management restrictions," "IP allowlisting," or "custom domain" are EE features — these were not found on any fetched page and should be treated as unconfirmed/absent from Onyx's current (2026) marketed feature set.
- "Curator role" / multi-tenant workspace teams were not explicitly found by name in the fetched sources; "User Groups & RBACs" and "Collaboration (shared chats and agents)" are the closest analogues found.
- Rate limiting controls and BYOK/encryption-key-management (customer-managed keys) were not confirmed; only "Encrypted Secrets" (encryption of stored credentials/API keys, not customer-managed key BYOK) was found in the EE docs.

## Question 3: Pricing tiers and feature-to-tier mapping

### Takeaway
As of this research (September 2026), onyx.app/pricing publicly lists two tiers by name in fetched content — a self-serve "Business" tier at $20/user/month (annual billing) and a custom-quote "Enterprise" tier — while other secondary sources also reference a free "Community" ($0, self-hosted MIT) tier and a "Scale" plan at $200/user/month; these secondary mentions could not be corroborated against the primary pricing page content actually fetched, so they are flagged as lower-confidence/possibly stale.

### Cited Findings
- Primary fetch of onyx.app/pricing (as processed) shows two tiers:
  - **Business** — "$20 per user/month (Annual Billing)" — includes: Chat and Search UI, Access to All Major LLMs, Custom AI Agents, Actions (MCP / OpenAPI), 40+ App Connectors, Web Search, Deep Research, Code Interpreter, Image Generation, Slack Integration, Developer APIs, Query History & Usage Dashboards, Basic Auth, Google OAuth, RBAC, Permission Inheritance, Encryption of Secrets, Community Support — [onyx.app/pricing](https://onyx.app/pricing)
  - **Enterprise** — "Flexible pricing & deployment options" (Contact sales) — "All Business features, plus": OIDC/SAML SSO, On-Premise Deployments, Region-Specific Deployments, Early Access to Features, White-labelling, Custom Integrations, Hook Extensions, Data Exports, Invoice Billing, Volume Discounts, Higher Education Pricing, Dedicated Support, Enterprise SLA — [onyx.app/pricing](https://onyx.app/pricing)
- A secondary aggregator source (not Onyx-owned) states: "Onyx AI pricing plans include: Community at $0, Onyx Cloud at $16/seat/month, and Enterprise at custom pricing. Additional tier information shows a Scale Plan priced at $200 per user per month for large communities and high-volume deployments, including priority feature access" — [SaaSworthy](https://www.saasworthy.com/product/onyx-app/pricing) — **note: this figure ($16/seat and $200/seat "Scale" plan) conflicts with the $20/user "Business" figure found on the primary onyx.app/pricing fetch and could not be reconciled; likely reflects pricing-page changes over time or aggregator staleness.**
- Community Edition (self-hosted, MIT-licensed, $0) is confirmed via the README/LICENSE analysis in Question 1 rather than the pricing page itself — [README.md](https://github.com/onyx-dot-app/onyx/blob/main/README.md)

### Inferences
- The tier structure is effectively three-layered in practice: (1) Community Edition — free, self-hosted, MIT-licensed, core Chat/RAG/Agents/Actions only, no `ee/` code entitlement; (2) Business — paid self-serve cloud tier ($20/user/month per the primary fetch) that already includes some code physically located under EE licensing terms (RBAC, permission inheritance, query history/usage dashboards), meaning Onyx-the-vendor extends a limited EE entitlement to Business customers via its own Cloud/contract rather than requiring a full "Enterprise License"; (3) Enterprise — custom-quote tier unlocking the remaining EE-licensed and infrastructure features (SSO/SAML/OIDC, whitelabeling, on-prem, hook extensions, dedicated support, SLA).
- This means a strict reading of "EE = paid license required" is only fully accurate for the Enterprise tier; several `ee/`-licensed code paths (RBAC, permission sync/inheritance, usage/query-history dashboards) are being commercially offered at the lower Business price point too, per the current pricing page.

### Gaps
- Could not reconcile the conflicting per-seat prices ($20/user per the primary onyx.app/pricing fetch vs. $16/seat "Onyx Cloud" and $200/user "Scale" plan per SaaSworthy) — this needs a direct human/browser re-check of onyx.app/pricing to confirm current 2026 numbers, since WebFetch tool summarization may have missed tiers or the aggregator may reflect an older/newer snapshot.
- Could not confirm whether a distinct free/self-serve "Cloud trial" tier (mentioned in the README as free with no feature limitations) is a permanent pricing tier or a time-limited trial only.
- No independent confirmation of higher-education-specific pricing figures or invoice-billing minimums.
